Selected work

  1. Runo · Chrome extension

    Saving WhatsApp Web chats into a CRM, with no API to do it

    Challenge
    Sales reps work in WhatsApp Web, and WhatsApp offers no API for reading those chats into a CRM.
    Approach
    A Manifest V3 extension that finds WhatsApp Web's internal chat store at runtime, resolves each contact to a phone number, and loads older history without switching the chat the rep has open.
    Impact
    Rep conversations reach the CRM without interrupting the rep. When WhatsApp ships a change the extension doesn't recognize, sync stops instead of guessing.

    JavaScript · Chrome Extensions (MV3) · Web Reverse EngineeringRead the case study →

  2. Runo · Flutter web

    One integration dialog for seven CRM connectors

    Challenge
    Every admin page in the Flutter web app had its own upload, mapping and validation code, and closing a dialog could wipe a half-finished mapping.
    Approach
    Shared browser-side sheet validation, one import wizard and an unsaved-changes guard, moved over one module at a time while ops kept working.
    Impact
    Core modules moved with no scheduled downtime, and the integration dialog now carries 7 CRM connectors: Zoho, Salesforce, HubSpot, Facebook Lead Ads, WhatsApp Business, S3 and GCS.

    7 connectorsRead the case study →

  3. Runo · Product analytics

    Analytics events you can trust in Amplitude

    Challenge
    Tracking calls sat directly on the Amplitude SDK inside feature screens, so staging events leaked into production and re-renders fired duplicates.
    Approach
    One typed analytics layer for the Flutter mobile and web apps: production-only routing, duplicate filtering, and a Hive buffer on the device flushed in batches.
    Impact
    About 15M events a month go through one layer. Test data stays out of production dashboards, and activity from offline sessions is sent once the connection returns.
