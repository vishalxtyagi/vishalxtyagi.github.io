Selected work

  1. Runo · Chrome extension

    Saving WhatsApp Web chats into a CRM, with no API to do it

    Sales reps live in WhatsApp Web, and WhatsApp offers no API for reading those chats. I built a Manifest V3 extension that finds WhatsApp Web's internal data stores at runtime and syncs conversations into the CRM.

    It loads a chat's older history without switching the chat the rep has open, and it stops rather than guesses when WhatsApp ships a change it doesn't recognize.

    JavaScript · Chrome MV3Read the case study →

  2. Runo · Flutter web

    One integration dialog for seven CRM connectors

    Each admin page in the Flutter web app had its own upload, mapping and validation code. I built shared pieces for those flows, including the integration dialog the admin app's connectors are built on: Zoho, Salesforce, HubSpot, Facebook Lead Ads, WhatsApp Business, AWS S3 and Google Cloud Storage.

    The migration happened while the ops team kept using the tools, with no scheduled downtime.

    Flutter web · Dart7 connectorsRead the case study →

  3. Runo · Product analytics

    Analytics events you can trust in Amplitude

    Tracking calls sat directly on the vendor SDK inside feature screens, so staging events leaked into production and re-renders fired duplicates. I replaced it with one typed analytics layer for the Flutter mobile and web apps.

    It keeps test and production data apart, filters duplicates, and buffers high-frequency events on the device so they survive bad connections and restarts.

    Flutter · Dart · Amplitude · Hive~15M events / monthRead the case study →
