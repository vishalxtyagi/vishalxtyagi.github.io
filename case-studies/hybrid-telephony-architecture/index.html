This case study explains the architectural refactoring behind Runo Hybrid Telephony — addressing how we eliminated session re-initialization when switching between Cloud and SIM calling.

Background: Cloud vs. SIM Calling

Cloud Telephony (virtual numbers) and SIM Telephony (cellular network) were both active features in Runo. However, because early architecture coupled the calling medium directly to session initialization, changing mediums required destroying and re-creating the user session.

Architectural Bottleneck: Session-Level Coupling

  1. Session Teardown: Users switching from SIM calling to Cloud calling had to log out or re-load their app profile.
  2. Local Cache Loss: Destroying the session purged local state (Hive caches, un-flushed analytics queues), forcing cold state reloads.
  3. Data Discrepancy: Separate data pipelines for SIM vs. Cloud calls caused discrepancies in reporting when users operated in both modes.

The Solution: In-App Hybrid Session State Machine

Instead of binding the calling medium to the global app session, we decoupled the calling mechanism into an In-App Dynamic Orchestration Layer:

sequenceDiagram
  participant U as User
  participant UI as Call Medium Selector
  participant Engine as Hybrid Session Engine
  participant Service as Telephony Adapter (Cloud / SIM)
  participant Log as Analytics & Call Log Queue

  U->>UI: Tap Dial Lead
  UI->>Engine: Check Hybrid Mode & Preference
  alt User selects SIM
    Engine->>Service: Trigger Native Cellular Intent
  else User selects Cloud
    Engine->>Service: Trigger Cloud VoIP Service
  end
  Service->>Log: Attach callMedium Tag (Cloud vs SIM) & Session ID

Benefits Shipped

  • Zero Session Downtime: Agents switch between Cloud and SIM calling per lead within a single session.
  • Unified Event Pipeline: Standardized callMedium metadata across logs, deleted logs, reports, and exports.
  • Admin Delegation: Admins can assign virtual numbers and hybrid permissions across user groups without requiring manual relogins on client devices.
