Product and integrations

  • Browser Extensions2026

    WhatsApp Web CRM Sidecar

    Sales reps' WhatsApp Web conversations never reached the CRM, and WhatsApp has no API for it. I built a Manifest V3 Chrome extension that finds WhatsApp's internal stores at runtime, syncs chats and call history in the background, and never changes the chat a rep is looking at.

    Case study

  • Product Analytics2026

    Product Analytics Pipeline

    Tracking calls were scattered through Flutter screens, so staging events polluted production dashboards, re-renders fired duplicates and offline activity was dropped. I built one typed analytics layer over Amplitude that fixes all three. It carries ~15M events a month and has reprocessed 45M in one run.

    Case study

  • Communication Workflows2026

    Hybrid Telephony Workflows

    Runo already supported SIM-based call tracking and Airtel IQ cloud telephony, but never together; an account got one or the other. I unified both into one account-level capability, usable at the same time in the same app.

    Case study

  • Platform Engineering2026

    Admin App Imports and Integrations

    Ops ran bulk imports and CRM integrations through admin pages that each parsed, validated and reported errors their own way, and a stray click could lose a half-finished mapping. I moved them onto one shared import and integration flow, module by module, while ops kept working. Seven connectors run on it today.

    Case study

  • Platform Engineering2025

    Manufacturing Inventory Platform Rebuild

    NMOLD's inventory ran on a rigid legacy stack: new product attributes needed schema migrations, operators typed counts by hand, and machine data never left the factory network. I led the rebuild in Flutter, Express and MongoDB and bridged the plant's PLCs into it. Live at one site.

    Case study
