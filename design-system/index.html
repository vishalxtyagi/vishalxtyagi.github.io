Design System

Typographic Notebook · single token source

Every color, type scale, and spacing value on this site traces to one place:DESIGN.md's frontmatter. No component reads a raw hex or pixel value — it reads a token name. This page is that token table made visible, not a second definition of it.

The base is Typographic Notebook: whitespace and type carry the hierarchy for long-form prose (case studies, notes, blog). A Fluent 2-derived elevation layer sits on top for dashboard-shaped UI — summary cards, at-a-glance metrics — where a bounded surface reads better than inline flow. Prose stays flat; cards get rounded.card and ashadow token, never one without the other.

Spacing & rhythm

  • space-y-20 / space-y-24 — between major page sections
  • max-w-[65ch] — long-form prose column, fixed regardless of viewport
  • line-height 1.75 — body copy, book-like reading rhythm
  • py-5 / py-6 — list and index-row spacing, grouping by whitespace instead of rules

Accessibility posture

Flat semantic HTML (article, header, nav) instead of div soup, and visible focus rings (see :focus-visible inglobal.css) rather than suppressed outlines. Motion is limited to color/opacity/transform transitions on hover and scroll; prefers-reduced-motionis checked directly in the command palette (CommandPalette.astro) and inglobal.css for scroll behavior — not yet for the hover-scale transform on feature-block cover images, which is the one gap this table surfaces.
