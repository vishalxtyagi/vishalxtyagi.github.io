Manufacturing Inventory Platform Rebuild

NMOLD's inventory ran on a rigid legacy stack: new product attributes needed schema migrations, operators typed counts by hand, and machine data never left the factory network. I led the rebuild in Flutter, Express and MongoDB and bridged the plant's PLCs into it. Live at one site.

What it does

NMOLD’s older inventory stack needed schema migrations for new product attributes. Floor operators typed counts by hand. PLC telemetry stayed on the factory network, so plant managers could not see machine state next to stock.

The rebuild uses document collections for flexible item attributes, one Flutter codebase for handheld and web, and a Node-RED + OPC UA bridge that streams controller events into the API. This shipped at one site, not a multi-site rollout.

PLC-to-IoT bridge, from the ground up: the initial version of the telemetry bridge was designed on ESP/NodeMCU hardware: the actual first step in getting Siemens/Delta PLC signals off the isolated factory network and into anything IoT-reachable, before the Node-RED/OPC UA layer sat on top of it. The same bridge also exposes a secured, tunneled remote dashboard, so a manager can switch the PLC-driven AC unit on or off from anywhere, not just from the plant floor.

Constraints

  • Item attributes vary widely: avoid constant relational migrations
  • Operators need phones; managers need dashboards
  • Siemens/Delta gear speaks OPC UA / Modbus on isolated networks
  • Warehouse Wi-Fi drops: clients need offline-tolerant behavior

Decisions & tradeoffs

  1. Express + MongoDB for flexible inventory documents
  2. Flutter for shared mobile/web UI
  3. Node-RED OPC UA adapter so industrial protocols stay out of core business handlers
  4. Lightweight image classification to help intake match part photos to catalog items

Tradeoffs: documents add attribute flexibility and push concurrency/validation into the app layer. An edge bridge adds a hop and keeps PLC protocol noise out of the API.

What it demonstrates

  • Migrating a manufacturing ops tool without pretending factory networks are the cloud
  • Cross-platform client consolidation
  • Bridging OT telemetry into a product inventory model
