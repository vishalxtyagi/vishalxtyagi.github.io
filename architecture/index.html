Architecture

Four production systems. Constraint, rejected option, and decision sit in one stack. Pick a component for the mechanism.

Constraint

SIM tracking and Airtel IQ already existed, but an account could only run one path. Both had to be live on one session, on Android, iOS, and admin web, gated by role and number allocation.

Rejected

Keep the account-level either/or flag and “switch mode” via reconfiguration. Reporting stays forked by mode.

Decision

A session orchestrator keeps both channel drivers active. Placement chooses a path at call time. Activity and reports carry callMedium.

Evidence: High confidence· Full spec

Constraint

Identical mobile/web behavior; traits attached automatically; events survive disconnects without blocking UI.

Rejected

Call Amplitude from feature views. Guard env inline. Fire identify on every re-render.

Decision

ProductAnalytics facade: env isolation, sliding-window dedup, Hive accumulator for high-frequency CRM activity, batch flush.

Evidence: High confidence· Full spec

Constraint

Ops had to keep using the Flutter web admin during cutover. Large sheets need in-browser pre-validation aligned with CRM schemas.

Rejected

Big-bang rewrite. Re-query org metadata on every wizard step. Trust dismiss not to wipe mappings.

Decision

Shared SheetValidationUtil, CustomStepper, wrapDialogWithDirtyCheck. Incremental module cutovers.

Evidence: High confidence· Full spec

Constraint

Tens of thousands of physical sheets, variable scan quality, institutional exam grading that cannot silently mis-score.

Rejected

A learned bubble detector (GPU, irreproducible scores) or folding warp/align/density into one pass.

Decision

Deterministic CV: persist warp, affine-align, relative histogram density, rule scoring, review queue for ambiguous marks.

Evidence: Verified· Full spec
