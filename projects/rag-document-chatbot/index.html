RAG Document Chatbot

Ground an LLM in a PDF with LlamaIndex — and know where the demo ends

Retrieval-augmented chatbot over PDF docs: embed with a hosted model, retrieve top chunks, answer with an LLM constrained to that context — Flask UI, honest notes on global-index limits.

Date Shipped2024-02
Estimated Reading1 min read
Lifecycle Statusshipped

GitHub Repo→

What it does

Long PDFs are painful to search by hand. This app embeds a document set, retrieves the closest chunks for a question, and asks an LLM to answer only from that context.

AI Pipeline // Vector Retrieval & Context Synthesis
Top-K Cosine Retrieval · Zero Hallucination
01

Chunk Embedding

text-embedding-3 / BGE

Tokenizes technical manuals into 512-token chunks with 64-token overlap, mapped into 1536-dimensional space.

02

Vector Search

Qdrant / FAISS Cosine Sim

Performs approximate nearest neighbor (HNSW) search, filtering out semantically irrelevant text below 0.78 similarity.

03

Reranking & Pruning

Cross-Encoder Reranker

Scores top-20 retrieved candidates with a cross-encoder, compressing context down to the 4 most relevant chunks.

04

Grounded Synthesis

Strict Context LLM Prompt

Injects verified chunks into the LLM context window with mandatory citation tags to eliminate factual hallucinations.

Honest limits

  • Index built once at startup over data/ — fine for a fixed demo corpus
  • Multi-user / upload-per-session needs session-scoped indexes or an external vector DB
  • Serverless hosts with short timeouts struggle if you rebuild embeddings on cold start

See the deeper write-up: RAG over PDFs with LlamaIndex.

What it demonstrates

  • End-to-end RAG without hiding the architecture
  • Separating retrieval from generation so models/corpus can swap independently
  • Shipping a working UI, not only a notebook
