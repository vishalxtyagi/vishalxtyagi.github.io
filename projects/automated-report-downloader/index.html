Automated Report Downloader

Python + Selenium automation that logs into the institute's internal feedback portal, walks every department and class, and bulk-exports each class's feedback as an Excel file — replacing a multi-hour manual click-through process.

Date2023-05
Reading Time2 min read
Statusshipped
StackPython, Selenium, Web Scraping

A browser automation script built for the institute’s feedback management system. The portal required staff to manually navigate to each department → each class → open a “Report” tab → click “Excel Export” — dozens of clicks per feedback collection cycle. This script does the entire batch in one run.

What the portal required manually

  1. Log in to the institution’s internal feedback portal
  2. Navigate to the feedback dashboard table
  3. For each department row: expand its class list
  4. For each class: load the feedback page, wait for the Report tab, trigger the Excel download
  5. Repeat for every class across every department

The portal had no bulk export, no API, and no way to script this except through the browser UI.

How the automation works

The script drives a headless Chrome instance via Selenium with webdriver_manager (no manual chromedriver install needed):

# Walk all department rows → collect class links
for row in dept_rows:
    class_links = row.find_elements(By.XPATH, './/a[contains(@href, "class")]')
    all_class_links.extend([c.get_attribute("href") for c in class_links])

# For each class: load, check for data, download Excel
for link in all_class_links:
    driver.get(link + "&bot=true")

    if driver.find_elements(By.XPATH, '//p[contains(text(),"No Feedback Found")]'):
        continue  # skip classes with no feedback

    wait.until(EC.element_to_be_clickable((By.ID, "nav-five-eg1-tab"))).click()
    wait.until(EC.element_to_be_clickable((By.ID, "ExcelReportButton"))).click()
    wait.until(EC.element_to_be_clickable((By.ID, "report"))).click()

Downloads go directly into a local Feedbacks/ directory via Chrome’s download preferences — no file-renaming or post-processing step needed since the portal names files per class.

Key details:

  • WebDriverWait with 15-second timeout on every navigation step (the portal was slow)
  • ?bot=true query param on class URLs — discovered to bypass a JS loading delay that broke navigation
  • Explicit empty-state check before attempting to click the export tab
  • time.sleep(2) after each download trigger to let the file land before navigating away

Collaborators and longevity

The script was originally written in May 2023 and was still in active use in April 2026, when a colleague updated it to handle a Chrome version change. That kind of maintenance gap — 3 years, real usage, adopted by another person — is a better signal of usefulness than any test suite.
