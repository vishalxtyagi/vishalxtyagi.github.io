    Exam answer sheets came in as scans with skew, noise and stray marks. I built a staged Python and OpenCV pipeline that normalizes, aligns and reads each sheet, and recovers a failed stage without rerunning the whole batch.

  2. Runo · Python, DuckDB

    A daily analytics pipeline, 42 minutes down to 3.8

    The daily call-analytics run recomputed everything from scratch. I rebuilt it as an incremental DuckDB pipeline that skips files it has already processed.

    42 min → 3.8 min

  3. Open source · Python, LlamaIndex, AWS

    An LLM that answers from your documents

    A retrieval-augmented chatbot over a company's documentation, deployed on AWS Lightsail: documents are embedded, the closest chunks are retrieved, and the LLM answers only from that context. The write-up covers scaling from one shared index to per-user indexes.
