Experience

  1. Software Engineer

    RunoJun 2025 – Present

    On a sales CRM, I take the problems that cut across the product and make them dependable: rep chats that never reached the CRM, analytics nobody could trust, calling modes an account couldn't combine, and a daily report run that took 42 minutes.

    • WhatsApp Web CRM extension: Sales reps work their leads in WhatsApp Web, and none of those conversations reached the CRM, because WhatsApp offers no API for it. I built a Manifest V3 Chrome extension that finds WhatsApp Web's internal data stores at runtime and syncs chats, contacts and call history in the background, without ever switching the chat the rep has open.
    • Integrations platform: Every CRM connector in the admin app was its own one-off screen, so each new integration meant rebuilding setup, validation and error handling from scratch. I replaced them with one setup flow they all share. Zoho, Salesforce, HubSpot, Facebook Lead Ads, WhatsApp Business, AWS S3 and Google Cloud Storage run on it today, and the next connector starts from it instead of from zero. 7 integrations
    • Product analytics: Tracking calls sat directly on the Amplitude SDK inside screens, so staging events leaked into production dashboards and re-renders fired duplicates. I replaced them with one typed analytics layer that keeps test data out, drops duplicates and buffers busy activity on the device. It carries ~15M events a month, and has reprocessed 45M in a single run. ~15M events/month
    • Call-analytics pipeline: The daily call-analytics run recomputed every file from scratch and took 42 minutes. I rebuilt it as an incremental DuckDB pipeline that only processes what is new. It now finishes in 3.8. 42 min → 3.8 min
    • Hybrid calling: An account could use SIM call tracking or cloud calling, never both, and changing that meant reconfiguring the account. I built the session handling that keeps both live, so an agent switches mode mid-shift without logging out, and replaced the on/off flag with per-call tracking so reports show which path each call used.
