  1. Software Engineer

I replaced them with one setup flow they all share.     • Product analytics: Tracking calls sat directly on the Amplitude SDK inside screens, so staging events leaked into production dashboards and re-renders fired duplicates. I replaced them with one typed analytics layer that keeps test data out, drops duplicates and buffers busy activity on the device. It carries ~15M events a month, and has reprocessed 45M in a single run. ~15M events/month

I built the session handling that keeps both live, so an agent switches mode mid-shift without logging out, and replaced the on/off flag with per-call tracking so reports show which path each call used.
