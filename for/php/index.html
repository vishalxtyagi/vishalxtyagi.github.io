Selected work

  1. Open source · Packagist

    Tamper alerts for Laravel apps on shared hosting

    Shared hosting has no file watchers or CI to notice when a deployed file changes. PHP Ghost Wall is a Composer package that hashes a monitored file on every boot and sends an alert, with server details, if it changed.

    PHP · Laravel · PackagistSee the project →

  2. Open source · Node.js, Laravel

    Laravel queue workers without Supervisor

    Laravel's queue worker expects Supervisor or systemd to keep it alive, and shared hosting has neither. I wrote a small Node.js process manager that starts the worker and restarts it when it dies.

    Node.js · PHP · LaravelSee the project →

  3. Production · Laravel 11, Filament

    A school's website and admin panel on shared hosting

    A Laravel 11 and Filament v3 CMS with role-based access, galleries and announcements, deployed automatically from a webhook and protected by PHP Ghost Wall.
